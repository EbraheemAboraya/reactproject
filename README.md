# Volunteer Platform — React Client

> A React and Vite frontend application with reusable UI components and API integration.

**Stack:** React · Vite · React Router · Axios · CSS

## Overview
This repository contains a frontend application structured around React components, client-side navigation and service/API modules. The source includes volunteer-related styling and reusable application components.

## Code organization
| Location | Purpose |
| --- | --- |
| `src/App.jsx` | Main application component |
| `src/components/` | Reusable interface components |
| `src/service/` | API/service integration |
| `src/http-common.js` | HTTP client configuration |
| `src/volunteer.css` | Feature styling |
| `public/` | Static assets |

## Run locally
```bash
npm install
npm run dev
```
Use the local address printed by Vite.

## Build and quality checks
```bash
npm run build
npm run lint
```

## What this showcases
Component-driven frontend architecture, HTTP service separation and React tooling. See also the [volunteer backend](https://github.com/EbraheemAboraya/volunteers) and [Volunify frontend](https://github.com/EbraheemAboraya/volunter_fronted) for related work.
